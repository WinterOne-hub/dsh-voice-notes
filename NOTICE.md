# Third-party components

Voice Notes is a community plugin for [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness). The plugin code is released under the MIT license in this directory.

- Harness provides the host, user interface and speech services. See the [Harness license](https://github.com/deepseek-ai/deepseek-harness/blob/master/LICENSE).
- Harness's SenseVoice provider prepares model resources from upstream sources. See the [SenseVoiceSmall model card](https://huggingface.co/FunAudioLLM/SenseVoiceSmall) and the [ONNX conversion used by the tested Harness release](https://huggingface.co/csukuangfj/sherpa-onnx-sense-voice-zh-en-ja-ko-yue-2024-07-17/tree/2365baeacb507f821a0c8120fcee3d484dba7a07). The upstream terms apply to the model weights. This package contains plugin code and documentation.

# 会议分析说明与后续计划

状态：「会议体检」和「表达解读（潜台词）」已在 `meeting-check` 分支实现实验版，尚未正式发布。其他扩展仍为草案。分析由用户手动发起。

## 会议体检

用户入口可使用「会议体检」，其中一个指标称为「废话含量（估计）」。正式指标名为「可压缩文字占比」，明确显示计算依据。

- 输入：用户确认过的转写和可选会议议题。优先使用校对后的多人转写。
- 分类：重复信息、无信息的填充语、偏离用户所填议题的内容，以及需保留和无法判断的内容。
- 说明：重复确认、风险提示、必要背景、寒暄和主持流程可能有实际作用，不能按关键词直接判断为冗余。没有议题时，不评估跑题。
- 计算：程序将原文拆为不重叠的片段，模型按片段编号分类；返回结果必须完整覆盖所有编号且没有重复。字符统计排除空白和标点。「可压缩文字占比 = 标为可压缩的有效字符数 ÷ 全部转写的有效字符数」。待确认内容不进入分子，单独显示占比。
- 输出：估计百分比、分类明细、可回听的原文依据和精简版。用户可把某段改为「需要保留」，指标随之重算。
- 边界：这是文本冗余的估计，不等于会议浪费时间的比例。当前时间戳是发言段级别，不能据此精确计算句子级浪费时长。短转写或转写缺失过多时不输出总分。

第一版按整场会议出报告。后续可增加个人复盘；不默认生成参会者排名。

## 表达解读

界面入口和报告标题为「表达解读（潜台词）」。每条采用相同结构：

| 内容 | 要求 |
| --- | --- |
| 原话与时间戳 | 引用原转写，支持回听，避免断章取义 |
| 可能含义 | 结合上下文提出一种解释，使用「可能」等明确措辞 |
| 其他解释 | 保留字面意思及其他合理解释 |
| 不确定之处 | 说明缺少哪些上下文，不生成虚假的置信度数值 |
| 澄清问法 | 给出中性、可直接向对方确认的问题 |

推测与明确事实分别展示。不据此断言某人撒谎、恶意或具有某种人格，也不通过声线推断心理状态。原文、说话人归属或上下文不足时标为「无法判断」。

每份最多 8 条。模型只能选择 1–3 个连续且属于同一发言段的片段编号，程序校验引用并从原文生成引文和时间戳，同时保留相邻原文。普通表述可返回空报告。界面支持回听、查看上下文和导出带实验说明的 TXT。输入限制与会议体检相同；两类报告分别保存和校验来源，不互相覆盖。模型返回不完整结构或无效引用时整份拒绝保存。自动测试覆盖结构和引用校验、空报告、待确认、权限、取消、旧报告保留和并发修改；尚未做真实会议解读质量评估。

重叠发言或未分配说话人的片段由程序设为「无法判断」，不显示模型推测。说话人归属和重叠标记计入来源校验；调整归属后旧报告失效。说话人显示名称不发送给模型，改名不影响报告。

## 可选扩展

- 承诺清单：列出谁承诺了什么，标明明确承诺、建议及未定事项。负责人和期限均须有原文依据。
- 会后一分钟：将讨论压缩为结论、分歧和下一步，链接到相关发言。
- 会议回放卡：展示议题变化、未决问题及发言时间分布。多人标签尚未校对时提示统计误差。

## 建议实施顺序

1. 先做会议体检：片段标注、程序计数、回听和人工保留，作为实验功能。
2. 用少量经许可的会议资料检验表达解读的引用和多种解释是否成立。
3. 之后再考虑统计图或分享卡片，避免先加入无法核对的分数。

建议复用现有历史卡片和模型选择流程，不另开录音模式。语言仍可选择，每份分析单独保存，不覆盖转写或事实纪要。

实验版保存每条录音的最新一次分析，重新分析成功后替换旧分析；失败或取消保留旧结果。支持中英文分析理由、半圆表盘、分类明细、发言段回听、人工保留和精简版。转写或人工判断发生并发变更时拒绝覆盖。输入至少 200 个有效字符，最多 40,000 个有效字符、80,000 个原始字符和 1,000 个片段；待确认比例达到 40% 时不显示总比例。阈值属于实验规则，尚未校准真实会议判断质量。

## 隐私与验收

每次调用前显示模型及要发送的文字范围；用户确认后才提交。说话人可默认使用编号，姓名替换不代表全文已匿名化。分享前提供预览，默认不带姓名和敏感原文。

用经参与者许可的录音或合成资料测试，覆盖重复确认、必要寒暄、主持流程、主题讨论、短插话、重叠语音和转写错误。检查所有引用能定位原文、百分比可复算、人工保留会重算指标、缺少上下文时会拒绝下结论。

现有版本的搜索标签只描述已发布功能。本草案中的功能在实现和验证后再加入介绍及标签。

# v0.0.4

- 新增电脑声音录制，支持耳机播放内容的转写和学习笔记。
- 新增会议体检，以表盘展示废话含量。
- 新增表达解读（潜台词），支持原话引用、回听和导出。

在插件工作台点击「检查更新」→「立即更新」，重启 Harness 生效。电脑声音和两项会议分析为实验功能。

## English

- Record computer playback audio and generate learning notes.
- View a meeting's estimated redundant-text share on a dial.
- Generate subtext interpretations with source quotes, playback and export.

Select **Check for updates → Update now**, then restart Harness. Computer audio and the two meeting analysis tools are experimental.

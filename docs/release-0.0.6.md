## English

- The record button shows the selected audio source.
- History puts playback, transcripts, and reports up front. Meeting check and subtext are under Analysis.
- Reports link to missing segments and use headings and lists. Search gets its own row in narrow windows.

Select **Check for updates → Update now**, then restart Harness.

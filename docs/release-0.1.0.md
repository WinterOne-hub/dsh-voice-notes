v0.1.0 延续 v0.0.10 的功能。已安装 v0.0.10 的用户可通过「检查更新」升级。

- 桌面字幕在定稿后逐句显示，每句按长度停留。
- 窗口跟随字幕尺寸，短句居中，长句换行。窗口缩放时保留吸边位置。
- 录音卡片的「删除」移至「重命名」旁。

## English

v0.1.0 carries forward the features in v0.0.10. Check for updates to upgrade from v0.0.10.

- Desktop captions display finalized sentences one at a time, with length-based reading time.
- The caption bar resizes to fit centered, wrapped text and stays docked when resized.
- Delete is now next to Rename on recording cards.

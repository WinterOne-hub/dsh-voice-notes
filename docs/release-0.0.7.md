# v0.0.7

- 工作台新增中英文「使用说明」，录音时也可查看。
- 工作台区分等待输入、正常录音和低音量。音频断流时结束录音，保留已采集内容。
- 在录音前展开「延迟诊断」并勾选测量。录音期间和停止后可查看临时字幕、正式转写和译文的样本数、中位数和 P95。

## English

- Open the bilingual in-app guide from the studio, including while recording.
- The studio distinguishes waiting for input, active recording, and low audio level. If input stops arriving, recording ends and captured audio is kept.
- Open **Latency diagnostics** and enable measurement before recording. View sample counts, median and P95 for interim captions, final transcripts and translations during or after recording.

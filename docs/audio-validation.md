# 录音与延迟实机验证

1. 在 Windows x64 和 macOS Apple Silicon 分别使用麦克风录制测试句，再戴耳机用「电脑声音」录制同一测试音频。每种来源确认开始时有波形、静音时仍继续录制、历史可回听和转写。
2. 电脑声音录到一半时切换默认输出设备。确认工作台提示设备变化、停止录制，历史回听和转写仍包含切换前的内容。用同样的方式检查拔掉外接麦克风后的结果。
3. 启用诊断，用合成或获授权的测试音频分别测试短句停顿和连续讲话。先预热一次，每种条件记录样本数、中位数和 P95，同时记录平台、Harness 版本、录音来源、识别模型、翻译模型和网络条件。记录缺少字幕、转写或译文的片段数量。

诊断以工作台收到的 PCM 为起点。首条临时字幕从该片段首个有声采样块计时，正式转写和首段译文从最后一个有声采样块计时。各统计只计入已显示的非空结果。测量包含排队和处理时间，系统驱动及音频传输到工作台之前的时间需另测。如需公布从发声到屏幕显示的延迟，可用外部设备同时拍摄屏幕和测试音源，逐帧核对发声与结果出现的时间。
